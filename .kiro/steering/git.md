- Always ask me before any git commit or push. Show me the file list and the commit message, then wait for my "yes".

- Commit messages are plain, short, imperative sentences. Never use em dashes. Use colons, commas, or periods instead.

- Never add "Co-authored-by" lines or any other trailer to commits.

- Never commit .env.local or any file matching .env* except .env.example.
